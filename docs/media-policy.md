# Media Policy

Venue media is essential profile content, not a premium feature.

- All claimed venues can upload original venue photos.
- Owner uploads require admin review before appearing publicly.
- Approved media appears on public venue pages.
- Rejected media does not appear publicly.
- Do not use scraped, copyrighted, stock, Instagram, or Google images unless properly licensed.
- Avoid tobacco, flavour, or advert-style images.
- Admins can approve or reject owner-uploaded media.
