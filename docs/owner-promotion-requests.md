# Owner Promotion Requests

Growth and Pro venue owners can request promotional campaigns from the owner dashboard.

- Growth and Pro venues can request promoted offers.
- Pro venues can request featured placements.
- Owners cannot publish promotions directly.
- Admin approval is required before anything goes live.
- Admin conversion creates a draft promoted offer or featured placement in the existing admin-managed systems.
- Promoted offer copy should avoid direct tobacco, shisha flavour, or smoking discount claims.
- Requests can be cancelled only while pending.
- Rejected requests show admin notes to the owner.
