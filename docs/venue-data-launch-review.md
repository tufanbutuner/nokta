## Required venue fields

- `slug`
- `name`
- `city`
- `area`
- `address`
- `postcode`
- `latitude`
- `longitude`
- `primary_category`
- `secondary_categories`
- image or fallback image

## Review notes

- Existing launch venues should remain in the shisha lounge launch wedge unless they have verified broader category data.
- Test-only venues should stay hidden from public users and visible only to configured admin accounts.
- Venue details can change; public pages should keep the direct-check disclaimer visible.
