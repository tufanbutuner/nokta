Homepage exploration · round 3

A layout inspired by Airbnb’s rhythm

Three takes on Airbnb’s discovery mechanics — the segmented search pill, the sticky category rail, horizontal carousels, the split map, and the tabbed inspiration grid — but re-skinned for Nokta: warm palette, category-neutral, and the dot kept as a quiet mark.

A

The Rail

Airbnb’s home glance: a single big search pill, then a sticky icon category rail, then horizontal carousels of venues.

  • Segmented Where / When / Who search pill
  • Sticky icon rail, active item underlined
  • “Open late”, “Big tables”, “New” carousels
  • Bento collections + offers
View A · Rail
B

The Atlas

Airbnb’s search view as the homepage: a scrollable list of venues beside a sticky map, with prices in the pins.

  • Split list + sticky map
  • Price-pill pins (the dot as the pin tip)
  • Hover a card → its pin lights up (and vice-versa)
  • Quick filter chips up top
View B · Atlas
C

The Mosaic

Airbnb’s editorial side: a full-bleed hero with the search overlapping, a bento of collections, and a tabbed inspiration grid.

  • Full-bleed hero + search pill
  • Bento “start with a mood” grid
  • Tabbed inspiration (Late-night / Terrace / Groups / Coffee)
  • Destination grid, Airbnb-footer style
View C · Mosaic
Round 4 · new

D · The Index — Booking.com-style list

A compact, centred search bar (not a segmented widget) with popular categories right beneath it, then a Booking.com-style results layout: left filter rail, sort and map strip, and result rows with star ratings, amenity details and price bands — written for lounges, restaurants and cafes, not hotels.
